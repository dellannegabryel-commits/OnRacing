# Carros e classes

Estética de competição: GT3, GT4, touring, LMP. Sem tuning de rua.

## Classes

| Classe | Exemplos (inspiração) | Potência aprox. | Peso aprox. |
|---|---|---|---|
| GT4 | Porsche 718 Cayman GT4, BMW M4 GT4 | ~400-450hp | ~1300kg |
| GT3 | Porsche 911 GT3 R, BMW M4 GT3, Ferrari 296 GT3 | ~500-550hp | ~1250kg |
| Touring (TCR) | Audi RS3 LMS, Honda Civic Type R TCR | ~340hp | ~1250kg |
| GTE | Ferrari 488 GTE, Porsche 911 RSR | ~500hp | ~1240kg |
| LMP2 | Oreca 07, Ligier JS P217 | ~600hp | ~930kg |
| LMP1/Hypercar | (topo) | ~700hp+ | ~1000kg |

## Licenciamento

- Preferência por carros reais licenciados; fallback: inspirados ("inspired by") com nomes próprios.
- Sem carros de rua.

## Equilíbrio (BoP)

- Balance of Performance por classe para corridas mistas.
- Em ranqueado: mesma classe obrigatória.

## Customização visual

- Livreias (cores, adesivos, números).
- Sem mudanças aerodinâmicas funcionais fora do setup.
