# Circuitos

Circuitos modelados a partir de layouts reais. Prioridade: traçado, elevação, curvas nomeadas, zonas de ultrapassagem.

## Lista inicial (v1)

| Circuito | País | Característica |
|---|---|---|
| Nürburgring Nordschleife | DE | Longo, elevação, curvas rápidas |
| Spa-Francorchamps | BE | Eau Rouge, Kemmel |
| Suzuka | JP | Figura-8, S curves |
| Monza | IT | Alta velocidade, chicanes |
| Interlagos | BR | Elevação, setor técnico |
| Laguna Seca | US | Corkscrew |
| Bathurst (Mount Panorama) | AU | Elevação extrema |
| Silverstone | UK | Fluxo rápido |

## Modelagem

- Fonte: dados GPS/lidar públicos + referências visuais.
- Malha de pista com largura real, zebras, runoff.
- Elevação e banking preservados.
- Zonas de DRS/ultrapassagem marcadas (apenas em modos com DRS).

## Variantes

- Layout completo e "curto" (quando aplicável).
- Dia/noite e clima.

## Escala

- 1:1 de traçado; compressão apenas se necessário por performance (documentar).
